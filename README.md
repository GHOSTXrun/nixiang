# UNBUILD

AI builds everything. We unbuild it.

基于 AI 逆向工程与“拆开互联网黑盒”主题的品牌概念和交互网页前端。

## 使用

直接打开 `index.html`，或者将仓库作为静态网站部署；不需要安装依赖或构建。Google Fonts 无法加载时会回退到系统字体。

## 功能

- 深色实验室界面与荧光绿立方体动效。
- 三种脚本拆解演示：炒作机器、推荐算法、无限路线图。
- 浏览器本地生成并下载 PNG 传播卡片。
- 桌面和手机布局，支持减少动态效果偏好。

## 项目状态

拟用名称 UNBUILD，拟用代号 $UNBUILD。当前为概念前端：终端输出是明确标注的脚本演示，没有 AI 分析后端，没有发行代币，没有官方合约地址，没有交易入口。名称与代号正式使用前还需检查重名。

传播方向：每天拆一个互联网黑盒，用“正在拆解 X → 发现里面其实是 Y”的反差结构邀请社区共创。口号：AI 构建一切，我们拆开一切。此概念不保证市场热度或投资回报。

## 验证

已在 Chrome 检查 1440px 桌面和 390px 手机布局；手机无横向溢出，终端可重复运行，切换对象后结果正确。

入口为仓库根目录 `index.html`。可以在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch、main、/(root)。提交源码本身不会自动启用 GitHub Pages。
