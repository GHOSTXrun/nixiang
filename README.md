# UNBUILD / Reverse Engineering Studio

基于视频参考重做的逆向工程工作台前端。黑蓝色高密度界面，顶部六个模块、两侧各四个工具、底部六个工具围绕中央终端，使用青色描边、微型流程图和橙色像素 Agent。

## 运行

直接打开 `index.html`。也可将整个目录部署为静态网站，无依赖、无构建步骤、无外部字体或脚本请求。必须同时保留 `styles.css` 和 `app.js`。

## 交互

- 自动播放的 24 步演示，终端日志、工具高亮、像素角色和分段进度条同步变化。
- 暂停 / 继续、重新开始、1× / 2× / 4× 速度，完成后可以重播。
- 点击工具查看详情，并将模块说明追踪到终端。
- Agent Session、Hex View、Call Graph 三个视图。
- Open File 在浏览器本地读取文件前 256 字节，不上传、不执行文件。
- 终端支持 `help`、`inspect`、`graph`、`hex`、`pause`、`resume`、`restart`、`clear`。
- 放大终端、Escape 还原、导出当前日志。
- 桌面与手机布局，键盘可操作的按钮与详情弹层。

## 边界

工作流、工具调用、调用图和分析结果是明确标注的本地脚本演示，没有真实逆向工程后端。工具名称表示视觉与流程参考，不表示这些工具已连接。Hex 视图的本地字节读取已实现。

UNBUILD 是独立概念；与 REA、Anthropic、OpenAI、pump.fun 无合作或背书关系。$UNBUILD 为拟用代号，没有发行代币或官方合约地址。

## 验证

Chrome 下检查了桌面 1440px 与手机 390px 布局，手机无横向溢出。检查涵盖暂停、速度切换、完整 24 步流程与重播、工具详情与追踪、放大与 Escape 还原、命令输入、真实本地样本的 Hex 字节结果和调用图切换。
