# UNBUILD / Launch website

视频参考风格的逆向工程工作台与项目官网。固定 4× 速度自动播放、自动循环；底部播放、重启、倍速、文件和导出按钮已移除。

## 运行

直接打开 `index.html`，或把整个目录静态托管。无依赖、无构建步骤。入口依赖 `styles.css`、`project-config.js` 和 `app.js`，同时保留 `assets/`。

## 已完成

- 20 个面板围绕中央终端，24 步脚本演示，日志、工具高亮、像素角色和进度条联动。
- 固定 4× 自动循环，保留工具详情、Agent / Hex / Graph 视图和终端放大。
- 项目介绍、四阶段理念、官方发行链接区、合约地址区、FAQ、社区区。
- 真实链接统一在 `project-config.js` 配置。空值时禁用链接和复制按钮。
- Logo、横幅、分享图和 `LAUNCH-KIT.txt` 中英发行文案。

## 正式发行前

填写 `project-config.js` 的真实官网地址、X、Telegram、pump.fun 项目链接及完整合约地址。公开发布实际创建者持仓、分配与费用选择等信息，不要填写未经确认的数字。当前这些信息尚未提供。

`assets/logo.png` 为 1024×1024，`assets/banner.png` 为 1500×500，`assets/share.png` 为 1200×630；原始矢量文件也已提供。按平台实际要求上传。配置真实 HTTPS 官网后网页会使用绝对 URL 设置分享图片及 canonical。

GitHub Pages 可使用 `main` 分支根目录。源码提交不等于已开启 Pages。网页托管、官方账号建立和代币创建是不同操作。

## 事实边界

工具调用、分析结果、Hex 字节与调用图均为脚本/样本演示，没有真实逆向分析后端。独立于 REA、Anthropic、OpenAI 和 pump.fun。没有虚构合约、购买入口、持仓、收益、审计、流动性或用户数据。
